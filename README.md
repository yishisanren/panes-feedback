# Panes — feedback

Bug reports and feature requests for **Panes**, an LSPosed module that turns your Android screen into a workbench: one main pane plus a column of live side panes.

This repository holds no source code. It is the place to tell the developer what went wrong or what you would like next.

- **Download and updates:** [LSPosed module repository releases](https://github.com/Xposed-Modules-Repo/io.github.yishisanren.panes/releases)
- **Report a bug:** [open a bug report](https://github.com/yishisanren/panes-feedback/issues/new?template=bug_report.yml)
- **Suggest a feature:** [open a feature request](https://github.com/yishisanren/panes-feedback/issues/new?template=feature_request.yml)

## Before you report a bug

1. Update to the latest version and reboot the phone once after installing. Most "nothing happens" problems come from skipping the reboot.
2. In LSPosed, check that Panes is enabled and that **System Framework** and **System UI** are ticked (plus your launcher, if LSPosed lists it as recommended).
3. Search [existing issues](https://github.com/yishisanren/panes-feedback/issues?q=is%3Aissue) — your problem may already have an answer.

## What makes a report fixable

- **A screen recording.** Most Panes problems are about what the screen does; a recording says more than a description.
- **The log.** In Panes settings open **Help & feedback → Export logs** right after the problem happens, and attach the file from your Download folder. Exporting needs root access (grant it to Panes in Magisk, KernelSU or APatch).
- **Your device.** Phone model, ROM name and version, Android version, Panes version.

The log holds only Panes's own steps: which windows it moved and when. It contains nothing from inside your apps. Issues here are public, so please check a recording for anything private before you attach it.

## Unlock and payment questions

Problems with an unlock code or a payment include your machine code and order details. Open an issue with the **Unlock or payment** template and leave out anything you do not want public; the developer will follow up there.
